# Week-4 Project Guidelines & Directives

## Git & GitHub Contribution Rules
- **Author Identity**: All commits must be made with `XiaoArnav <322868724+XiaoArnav@users.noreply.github.com>`.
- **Target Branch**: Work directly on `main` or merge all work into `main` before pushing to guarantee GitHub contribution dots.
- **Push Cadence**: Push changes to `origin main` after completing any discrete milestone or documentation update.
- **Conventional Commits**: Format commit messages using standard prefixes: `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`.
